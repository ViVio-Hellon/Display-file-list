# 変更履歴

版は `config/app.json` の `version` だけが出どころです。上げたら、ここに節を足してください。

## VER1.7.0(2026-11-03)

- **フォルダの一覧も取れるようにした**(指示: ファイル一覧に選択ボタンを付けて、フォルダの一覧取得も可能に)。
  「1 ファイル名取得」に「一覧にするもの: ファイル / フォルダ」の選択ボタン。初めは「ファイル」(これまでどおり)
  - 「フォルダ」を選ぶと、指定したフォルダの**直下のフォルダ**(隠しも含む。その下は見ない)の一覧。ファイルは出さない
  - ボタンの名前も「フォルダ名取得」に変わる。見出しは「◯◯ のフォルダ一覧」
  - 列は 文書番号 / 名称 / 更新日時(フォルダには拡張子が無いので、その列は出さない)。コピー・印刷も同じ3列
  - 名前は**最初の `_` で分ける**(ファイルと同じ)。`_` が無ければ名前全体が名称。**`.` では分けない**
    (ファイルの分け方だと `99.生産管理課 土曜日出勤者` が名称「99」になってしまうため)
  - `abc_` のように `_` で終わる名前は、名称を空欄にして理由を添える(ファイルと同じ)
  - 並べ替えはファイルと同じ(文書番号の先頭の数字・先頭 300 件・空欄は後ろで読んだ順)
  - 選んだもの(ファイル / フォルダ)は覚えておき、次に開いたときも同じものが選ばれている
- API: `GET /api/filelist?target=files|folders`(省くとファイル。ほかの値は 422)。答えに `target`
- 試験: フォルダ名の分け方・直下だけ・API・覚え書き・コピーと印刷の3列(150 件)

## VER1.6.2(2026-10-19)

- **画面の割合を 結果:操作 = 6:4 にした**(指示: いまは 8:2 ぐらい。6:4 に。フォルダのパスを入れる欄をもっと長く)。
  これまでは操作の幅が 360px 固定だった。操作の幅は 4 割で、360px より狭くはしない
- フォルダのパスの欄は操作の幅いっぱいなので、一緒に長くなる(幅 1882px の画面で 約 330px → 706px、1366px で 500px)
- 幅 900px 以下で縦に積むのは変えていない。どの幅でも横のスクロールは出ない(1882 / 1366 / 1000px で確かめた)

## VER1.6.1(2026-10-17)

- **印刷がはみ出していたのを直した**(指示: 余白 5mm 内側にしないとはみ出す。coil-packing-tools の印刷の設定を確認)。
  プリンターは紙の縁 約 4mm に刷れないのに、紙面の距離を `@page` の余白で取っていたので、印刷の窓で
  余白「なし」を選ぶ(またはそれを覚えている)と紙の端から刷られていた
  - coil-packing-tools(梱包明細・資材計算・ペナラベル)と同じ決まりにした: `@page` の余白は 0、距離は
    **紙の中**(紙面の内側 8mm)で取る。印刷の窓の余白が「デフォルト」でも「なし」でも同じ位置に刷る。
    2 枚目以降の紙の上端・下端も同じだけ空ける(`box-decoration-break: clone`)
  - 「背景のグラフィック」の設定に関わらず同じ色で刷る(見出しの網掛け・薄い字)
  - **右下のページ番号はなくした。** 余白が 0 なので置く場所が紙の縁(刷れない所)になるため。
    ブラウザが余白に入れる日付・URL も刷られない
  - Chromium で PDF にして 300dpi で測った: 112 件・3 枚とも、インクは紙の端から 7.8mm 以上内側
    (上 8.0〜8.8 / 下 8.4〜 / 左 8.0 / 右 7.8)。一覧が無いときの紙も 8.2mm 以上
- 試験: `@page` の余白が 0 だけ・紙の中で 5mm 以上・2 枚目以降も空ける・色を固定・余白に物を置かない(`tests/test_print_margins.py`)

## VER1.6.0(2026-10-16)

- **「一覧を印刷」**(指示: 一覧を印刷する機能をつけてください)。表示中の一覧を、画面と同じ並びで印刷する
  - 紙面は A4 縦。頭に「◯◯ の一覧」とフォルダ・取得時刻・件数・印刷時刻。列は 文書番号 / 名称 / 更新日時 / 拡張子(コピーと同じ)
  - 見出し行はページごとに繰り返し、右下にページ番号(1 / 3 など)。行の途中でページを分けない
  - 取り直さない(画面に出ている一覧そのもの)。一覧が無いうちは押せない
  - 一覧を取ったあとでファイル名を直したときは、紙にも「いまのフォルダとは違います」と書く。並べ替えが先頭 300 件までのときもその旨を書く
  - Ctrl+P で印刷しても同じ紙面。一覧が無いときは白紙にせず「印刷する一覧がありません」と出す
  - 別の窓もサーバの経路(VER1.3 までの `/print`)も使わない。画面の中に紙面を作り、印刷のときだけそれを出す。ダウンロードはしない
- 紙面を作る JS(`app/static/js/printsheet.js`)を node で動かす試験(`tests/test_print_sheet.py`)
- 「一覧をコピー」「一覧を印刷」は「ファイル名取得」の下の行に並べた(幅の狭い操作欄でボタンの字が折れないように)

## VER1.4.1(2026-10-16)

all-tools(1.5.25)で起きた「起動に失敗した Python が stop.bat で止まらず、フォルダを消せない」と
同じ状況になりうる所を直した。

- **stop.bat が止まったのを確かめずに「正常に終了しました」と言っていた**(all-tools と同じ)。止める合図を受け付けても、
  PID が居なくならなければ PID で止め(照合してから。Windows は子ごと `taskkill /T`)、それでも残れば
  「止まりませんでした(pid …)」と言う。待ち受けがまだ答えているときは待たずにすぐ PID へ
- **止める入口(process_manager.py)を標準ライブラリだけにした。** これまで app\core と launch_guard.py を読んでいたので、
  フォルダが途中まで消えた状態では stop.bat そのものが動かなかった。いまは app\・config\ が無くても動く
  (プロセスの道具は process_manager.py の1か所に置き、launch_guard.py がそれを使う)
- **起動に失敗したとき黙って消えない。** 部品(app\services など)が欠けていれば、無いものを名指しして
  「配布フォルダを丸ごと入れ直してください」と出す(Start.vbs からならメッセージの窓、start.bat ならコンソール)。
  設定ファイルが壊れているとき・本体の組み立てで落ちたときも、理由を出して launcher.log に残す。ロックは残さない
- **待機画面も心拍を送る。** 準備に失敗して理由を出している画面を閉じれば、少しして Python が自分で終わる
  (これまでは stop.bat で止めるまで残っていた)。止める合図(`/api/shutdown`)にはこの状態でも答える(試験で確かめる)

## VER1.3.0(2026-10-16)

**ログ機能**(指示: 「ログ機能を付けてください。vba-daily-report-python-migration 参照。ログの掃き出し先も指定できるように」)。
日報管理ツール v4.1.0 の「エラーを後から追う」を、このツールの画面と操作に合わせて写した。

- 出来事に番号(`E1016-0912-7KX`)。予期しないエラーは画面にも同じ番号を出し、HTML の画面なら番号つきのエラーの頁
- 残すもの: 操作(ファイル名取得・ファイル名変換・画面を開いた)・断り(画面に出た文言ごと)・エラー(例外・コードの場所・traceback)・警告(1分に1度)・起動と終了・リネームの結果・出力先の変更
- 画面(ブラウザ)のエラーも、押したボタンの名前15件を添えて記録(1分に30件まで)
- ログの面(上の帯の「ログ」。まだ対策済にしていないエラーの数つき): 期間・見るもの・端末・番号や文言で絞る一覧 / なぜなぜシート(経過・送った中身・手がかり・なぜ1〜5・対策・状態)/ CSV を出力先の「書き出し」へ
- **ログの出力先を指定できる**。空ならこの端末の logs。共有フォルダなら全端末の記録が1つの一覧に並ぶ(ファイル名に端末)。その場で書き先が移る。書けなくなったらこの端末へ書いて5分ごとに試す。server.log・app.log も出力先へ(launcher.log はこの端末のまま)
- 180日より古い、この端末のぶんを起動のときに消す

## VER1.2.0(2026-10-16)

- **フォルダはパスを打つだけにした**(指示どおり)。班のボタン(A班〜昼(日勤)・基準フォルダ)、基準フォルダの設定、「基準フォルダを入れる」「選んだ班のフォルダを入れる」「参照…」をなくした
- **「パスを指定しても見つからない」を直した。** エクスプローラーの「パスのコピー」は前後に `"` を付けるが、それを外さずに相対パスと読み、アプリのフォルダの下を探していた。前後の `"`・全角の空白・`file:///` の形を取り除いて読む(`app/services/folder_input.py`)。相対パスは断る
- 断るときに**読んだパス**を出す(何を探して見つからなかったのかが見えるように)。読めなかった入力はログ(app.log)にも残す
- 最後に使えたパスを覚えておき、次に開いたときに入れる。Enter でも実行できる
- 印刷の見出しはフォルダの名前(「A班 一覧」など)
