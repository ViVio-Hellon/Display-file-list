# 変更履歴

版は `config/app.json` の `version` だけが出どころです。上げたら、ここに節を足してください。

## VER1.1.0(2026-10-15)

ブックから書き出した VBA(`vba/export/` の UF.frm・UF.frx・記録.bas・全角文字を半角文字に.bas)を受け取って反映。

- 画面の表記をフォームに合わせた: 「ファイル名取得」「ファイル名変換(全角を半角に)」「PDF作成 / 印刷」「フォルダも対象」、変換対象の文字の4行(全角数字 → 半角数字 など)
- 昼のボタンは「昼(日勤)」と出す(フォームの表記は「昼」、読むフォルダは「日勤」)
- 直すフォルダの初期値を基準フォルダにした(フォームの T2 は初めから「ThisWorkbook.Path」が入っていた)
- 試験が VBA の書き出しそのものを読むようにした: 変換表・班のフォルダ名・並べ替えの 300 行・フォルダが無いときの文言・フォームの表記
- ポートの空き確認を待ち受けと同じソケット設定にした。Windows では SO_EXCLUSIVEADDRUSE(ほかのアプリが待ち受け中のポートに重ねて開かない)、それ以外では SO_REUSEADDR(閉じた直後の接続が残っていても開ける)

## VER1.0.0(2026-10-15)

Excel VBA「ファイル名一覧取得」の Web 版として初版。

- 一覧: 班(A班〜D班・日勤・基準フォルダ)のファイルを 文書番号 / 名称 / 更新日時 / 拡張子 で表示。分け方・並べ替えは VBA どおり
- 直したところ: `_` が2つ以上のファイルも一覧に出す(最初の `_` で分ける)・`_` で終わる名前で止まらない(移植計画 Q2・Q3)
- 印刷 / PDF: 印刷用の紙面を別の窓に出し、ブラウザの「PDF として保存」で保存(Q8)
- 全角→半角リネーム: 変わる名前を見てから実行(Q14)。同名は `_1` `_2`…、フォルダの衝突は変えない(VBA どおり)。使えない字になるものは試す前に止める
- 起動基盤: 起動待機画面・多重起動防止・ログ(launcher / server / app)・安全な停止・画面を閉じたら自動終了。標準ライブラリだけ
- 照合: `vba/照合用_一覧をCSVで書き出す.bas` と `scripts/compare_with_vba.py`
