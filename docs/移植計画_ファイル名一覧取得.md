## 1. この VBA は何をしているか

**班ごとのフォルダに置いた文書(作業手順書など)のファイル名を読み、
「文書番号 / 名称 / 更新日時 / 拡張子」の一覧表をシートに作る**ツールです。
あわせて次の2つを持ちます。

- 一覧などのシートを **PDF にしてブックと同じフォルダへ保存**する
- フォルダ内のファイル名(とフォルダ名)の **全角英数字・記号を半角に直してリネーム**する

ファイル名は `文書番号_作業名.拡張子`(例 `6-4-2-3_新５点バキューム作業.pdf`)という
決まりで付けられている前提です(コード中のコメントより)。

**Access・DB・他ブックへの依存はありません。** 読むのはフォルダとファイル名だけ、
書くのは自分のシート・PDF・ファイル名だけです。

### 2.3 一覧作成 `Get_FileName` の規則(VBA どおり)

1. 対象フォルダを決める(2.1)。無ければ「指定のフォルダは存在しません。」で中止
2. シート「一覧」が無ければ先頭に作り、全セルの値を消す
3. `FileSystemObject.Files` の順で**全ファイル**(隠し・システムファイルも含む。サブフォルダは見ない)を1行ずつ書く。
   1行目から書き、見出し行は無い
4. ファイル名を `_` で分けた個数で分岐

| `_` の数 | A: 並べ替えキー | B: 文書番号 | C: 名称 | D: 更新日時 | E: 拡張子 |
|---|---|---|---|---|---|
| 1個 | `Val(最初の"-"より前)`。0 なら空欄。`_`より前が空なら空欄 | `_`より前(文字列として) | `_`より後ろを`.`で分けた**先頭** | 最終更新日時 | `_`より後ろを`.`で分けた**最後** |
| 0個 | 空欄 | 空欄 | 最後の`.`より後ろを拡張子とし、`"." & 拡張子` を**すべて**取り除いた残り | 最終更新日時 | 最後の`.`より後ろ(`.`が無ければ名前全体) |
| 2個以上 | **何も書かない(空行)** | | | | |

   - 1個のとき、`_`より後ろが `.` で始まる(`abc_.pdf`)と C・E は空欄
   - 1個のとき、`_`より後ろが空(`abc_`)だと **実行時エラーで止まる**
5. A〜E の 1〜300 行目を A 列の昇順で並べ替え(数値が先、空欄は後ろで元の順)
6. A 列を削除 → 最終形は **A 文書番号 / B 名称 / C 更新日時 / D 拡張子**

### 2.4 全角→半角リネームの規則

- 変換対象は **U+FF01〜U+FF5E(！〜～)を U+0021〜U+007E に、U+3000(全角空白)を半角空白に** の 95 文字だけ。
  カタカナ・「〜」(U+301C)・「−」(U+2212)・「￥」(U+FFE5) などはそのまま。英字の大文字小文字は変えない
- ファイル → (チェック時)直下フォルダ の順に処理。サブフォルダの中は見ない(UI は `recursive=False` 固定)
- ファイル: 変換後の名前が既にあれば `名前_1.拡張子`、それも有れば `_2`… と空きを探す
- フォルダ: 変換後の名前が既にあれば失敗として数え、変えない
- 結果は `Debug.Print`(イミディエイトウィンドウ)にしか出ない。利用者には何も表示されない

### 2.5 PDF 保存

`ThisWorkbook.Sheets(T1)` を `ブックの場所\T1.pdf` へ、印刷範囲の設定どおり **1ページ目だけ** 出力。
同名の PDF は黙って上書き。シート名が無いと実行時エラー。

## 8. DB・運用まわりの確認事項への回答

| 確認事項 | この機能での答え |
|---|---|
| Access → SQLite | **該当なし。** VBA は DB を使わない。一覧は毎回フォルダから作り、DB に持たない |
| SQL 方言・型 | 該当なし |
| 複数PCの同時書き込み・`database is locked` | DB に書かないので起きない。保存するのは各PCの設定 JSON だけ |
| 共有フォルダ上の SQLite | 使わない(既存ツールは取り込み元 sqlite3 を読み取り専用+写しで扱い済み) |
| 長時間放置・古いデータ | 一覧に「取得時刻」を出し、**リネームは実行の瞬間にフォルダを読み直す**(画面の古い一覧で決めない) |
| 接続の保持 | 持たない(フォルダは要求ごとに読む)。既存の DB 接続も要求ごと |
| セッション切れ・放置後の操作 | 既存の仕組み(心拍・自動終了・接続断の帯・トークン)がそのまま効く |
| 日付変更・マスタ更新後 | 状態を持たないので影響なし |
| 複数PCが同じフォルダを同時にリネーム | `os.rename` は相手先があると失敗するので**上書きは起きない**。失敗はその件として報告。VBA(有無を見てから移動)と同じく競合時は片方が失敗する |
| ファイル名として使えない文字 | `＼／：＊？＂＜＞｜` は半角にすると Windows で使えない。VBA は移動に失敗して数えるだけ。Python は**移動を試す前に失敗として扱う**(`/` がフォルダの区切りに化けて別の場所へ動くのを防ぐ) |
| ファイルハンドル・ロック | 開いたままにしない(`os.scandir` を with で閉じる)。他人が開いている Office ファイルはリネーム失敗として報告 |

## 9. 移植方針

1. **判定は Python の純関数に**(ファイル名 → 1行)。走査と分けて、名前だけで試験できる形にする
2. **VBA の癖は既定で再現**し、直すものは確認後に1つずつ(K1〜K9)
3. 既存の半角化の表は **1か所にまとめて全員がそれを使う**(挙動は変えない。既存の試験で確かめる)
4. 画面は既存の作法(結果は左・操作は右、文言はサーバ、422 で断る)
5. ダウンロードは使わない。印刷画面とフォルダへの保存だけ
6. 権限が要るなら `access_control.permissions()` に1つ足す(Q13)

### 実装の順番(確認後)

1. `vba_compat.val` と一覧の純関数 + 試験(VBA の結果表と突き合わせ)
2. 半角化の共通化 + リネーム(下見 → 実行)+ 試験(一時フォルダで実ファイル)
3. 画面・API・設定(基準フォルダ)
4. 印刷 / PDF(Q8 の決定どおり)

- 名前ごとの分岐(`_` 0/1/2個以上、`.` 0/1/複数、空、先頭`_`、`~$`、`&H`、指数、空白入り、全角数字)
- 並べ替え(数値の昇順・同値は元の順・空欄は後ろ・300行の境目)
- 変換表 95+1 文字の全件、対象外の文字(カタカナ・〜・−・￥)
- リネームの衝突(`_1` `_2`…、フォルダは失敗)、使えない文字、権限の無いファイル、存在しないフォルダ、空入力
- VBA との照合: 実フォルダで作った VBA の「一覧」(CSV で書き出したもの)を正解にした比較
