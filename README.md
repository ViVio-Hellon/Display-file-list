# ファイル名一覧取得(Web 版)— VER1.3.0

Excel VBA「ファイル名一覧取得」をブラウザで使えるようにしたものです。
**Python の標準ライブラリだけ**で動きます(Flask などの追加は要りません)。

指定したフォルダにある文書のファイル名を
**文書番号 / 名称 / 更新日時 / 拡張子** の一覧にし、印刷(PDF 保存)できます。
ファイル名の全角英数字・記号を半角に直すこともできます。

| 文書 | 中身 |
|---|---|
| [`docs/移植計画_ファイル名一覧取得.md`](docs/移植計画_ファイル名一覧取得.md) | VBA の解析・決まったこと・不明点・DB/運用の確認 |
| [`docs/変更履歴.md`](docs/変更履歴.md) | 版ごとの変更 |
| [`vba/export/`](vba/export) | 移植元の VBA。ブックから書き出したもの(UF.frm / UF.frx / 記録.bas / 全角文字を半角文字に.bas、CP932 のまま) |
| [`vba/原本_ファイル名一覧取得.txt`](vba/原本_ファイル名一覧取得.txt) | 最初に貼り付けてもらった VBA(export と同じ。`ListFilesInFolder` だけ export に無い) |
| [`vba/照合用_一覧をCSVで書き出す.bas`](vba/照合用_一覧をCSVで書き出す.bas) | VBA の結果と突き合わせるためのマクロ |

## 使い方

| ファイル | 使うとき |
|---|---|
| **`Start.vbs`** | **ふだんはこれ。** ダブルクリックすると、ブラウザに画面が出ます |
| `start.bat` | 起動しないとき。コンソールに理由が出ます(`start.bat --check` は確認だけ) |
| `stop.bat` | 止めるとき。画面の「終了」でも止まります。画面を閉じても約8秒で止まります |

1. 「1 ファイル名取得」にフォルダのパスを貼り付けて「ファイル名取得」(Enter でも可)。
   パスはエクスプローラーのアドレス欄、または「パスのコピー」で写したもの(前後の `"` は付いたままで大丈夫)
2. 「PDF作成 / 印刷」で別の窓に一覧の紙面が出ます。PDF にするときは印刷先で「PDF として保存」を選びます
3. ファイル名を直すときは「2 ファイル名変換」にフォルダのパスを入れて「変わる名前を見る」→
   左の一覧を確かめて「この内容で直す」。**見るだけでは何も変えません**

最後に使えたパスは覚えておき、次に開いたときに入っています。

設定・起動の記録は `%LOCALAPPDATA%\FileListTool` に置きます(アプリ本体を共有フォルダに置いても、共有側を汚しません)。

## ログ ── エラーを後から追う(VER1.3.0)

日報管理ツール(vba-daily-report-python-migration v4.1.0)の「エラーを後から追う」を写しました。
画面右上の **「ログ」** で開きます(この2日のまだ対策済にしていないエラーの数が出ます)。

| | 中身 |
|---|---|
| 番号 | 1件ずつ `E1016-0912-7KX` のような番号(頭の1文字が種類、続いて月日・時分、見間違えない3文字)。予期しないエラーは画面にも同じ番号を出す |
| 残すもの | 押した操作・ファイル名取得・**断りとエラーは全部**・警告・起動と終了・ログの出力先の変更・リネームの結果。心拍や読むだけの問い合わせは残さない |
| なぜなぜの材料 | 起きたこと(いつ・端末・画面・操作・何と出た)/ 直接の原因(例外とコードの場所・traceback)/ そのときの状態(フォルダ・版)/ それまでの経過(同じタブの前30分・後5分)/ 送った中身(合言葉などは `***`) |
| 画面のエラー | ブラウザの中で起きたエラーも、直前に押したボタン15件を添えて記録し、番号を出す(打った値は送らない) |
| なぜなぜシート | 一覧の行を押すと開く。なぜ1〜5・対策・状態(未着手 / 対策中 / 対策済)・書いた人を残す |
| CSV | いまの絞り込みのまま、出力先の `書き出し\エラー一覧_日時.csv` へ(Excel で開ける。ダウンロードはしない) |

### ログの出力先

ログの面の「ログの出力先」で決めます。**その場で書き先が移ります**(起動し直さなくてよい)。

- 空なら**この端末の** `%LOCALAPPDATA%\FileListTool\logs`
- **共有フォルダを指せば、どの端末で起きたエラーも1つの一覧に並ぶ**。ファイル名に端末の名前が入るので混ざらない
  (`出来事_2026-10-16_PC-L1.jsonl`・`なぜなぜ_PC-L1.jsonl`・`app_PC-L1.log`・`server_PC-L1.log`)
- 保存するときに書けるか確かめる(書けなければ理由を出して保存しない)。あとで届かなくなったときは
  **この端末の logs へ書き**、5分ごとに出力先を試す(ログの面と「ログ」に、書けていないと出る)
- **起動の記録(launcher.log)は従わない。** 起動できないときに読むものなので、いつもこの端末
- 残すのは **180日**。起動のたびに、それより古い**この端末のぶん**だけ消す(ほかの端末のファイルには触らない)

## VBA との対応

| VBA | Web 版 |
|---|---|
| UserForm `UF` / `UFOP` | 画面 `/`(結果は左・操作は右) |
| `OBA`〜`OBHIRU`(A / B / C / D / 昼)+ `ThisWorkbook.Path` | フォルダのパスを打つ(VER1.2.0。班のボタンと基準フォルダはなくした) |
| T2(初期値 `ThisWorkbook.Path`) | フォルダのパスを打つ。最後に使えたパスが入っている |
| `Get_FileName` + シート「一覧」 | `app/services/file_list_service.py` + `GET /api/filelist` |
| `Val` | `app/services/vba_compat.py` |
| `PDFCREATE` | `GET /print`(印刷用 HTML)→ ブラウザの「PDF として保存」 |
| `ExecuteRenameBasicErrorHandling` ほか | `app/services/rename_service.py` + `POST /api/rename/preview` → `/run` |
| `ConvertZenkakuToHankaku` | `app/services/halfwidth.py`(VBA ソースの表と同じことを試験で確かめる) |

| `MsgBox "指定のフォルダは存在しません。"` | 画面に同じ文言 |

### VBA から変えたところ

| 何を | VBA | Web 版 | 根拠 |
|---|---|---|---|
| `_` が2つ以上のファイル | 空行になり一覧に出ない | 最初の `_` で分けて一覧に出す(`6-4_手順_改.pdf` → 6-4 / 手順_改) | Q2「ミス、直す」 |
| `_` で終わる名前(`abc_`) | 実行時エラーで止まる | 止めずに名称・拡張子を空欄、理由を添える | Q3 |
| リネーム | 押すとすぐ変える | 変わる名前を見せてから変える | Q14 |
| リネームの結果 | イミディエイトウィンドウだけ | 画面に1件ずつ出す | — |
| 使えない字になるリネーム(`／`→`/` など) | 移動を試して失敗 | 試す前に失敗とする(結果は同じ) | `/` が区切りになって別の場所へ動くのを防ぐ |
| PDF | 1ページ目だけをブックの場所へ保存 | 印刷画面から保存(全ページ。1ページ目だけは印刷画面で指定) | Q8 (a) |
| 紙面 | 見出し行なし | 見出し行・フォルダ・取得時刻を付ける | 紙で読めるように |
| 一覧を取るフォルダ | 班のボタン(A / B / C / D / 昼)でブックの場所の下の班フォルダ | フォルダのパスを打つ | 2026-10-16 の指示 |
| PDF にするもの | T1 に書いたシートを、そのシートの印刷範囲どおりに(Excel の設定が要る) | 画面に出した一覧そのもの(印刷範囲の設定は要らない) | Excel を使わないため |

### そのまま残した VBA の動き

`12-1_手順書.v2.xlsx` は名称「手順書」(間の v2 は出ない)/ 拡張子の無いファイルは拡張子の欄に名前 /
`a.txt.txt` は名称「a」/ 並べ替えは先頭 300 件まで(超えたら画面で知らせる)/
並べ替えキーは VBA の `Val`(空白を詰める・`&H` は16進・`1e3` は指数)/ 隠しファイルも載る。
正解の一覧は [`tests/golden/vba_cases.json`](tests/golden/vba_cases.json)(VBA のコードから手で書いたもの)。

## VBA の結果と突き合わせる

1. Excel 版で班を選んで「ファイル名取得」
2. `vba/照合用_一覧をCSVで書き出す.bas` を VBE で取り込み、`ExportListToCsv` を実行
   → ブックの場所に `一覧_照合用.csv`
3. 同じ PC で `python scripts\compare_with_vba.py --csv "…\一覧_照合用.csv" --folder "…\A班"`

Python 側を**直す前の VBA と同じ動き**にして行ごとに比べ、違いがあれば行・項目・手がかりを出します。
直したところ(Q2)で変わるファイルは「意図した違い」として別に出します。

## 作り

```
Start.vbs ─▶ start_app.py ─▶ launch_guard.py(多重起動)─▶ server.py(127.0.0.1 で待ち受け)
start.bat ─▶ 同じ道(コンソール表示)                         ├─ /loading 待機画面
stop.bat  ─▶ process_manager.py ─▶ /api/shutdown → 応答が無ければ PID(照合してから)
app/
  application.py   守り(トークン・Host・同一オリジン)・書き込みの直列化・出来事の記録(番号)
  core/event_rules.py  ログの決まり(番号・残すもの・経過・なぜなぜシート・CSV の行)。純粋
  core/event_log.py    ログを書く(裏のスレッド・書けなければ手元へ)・読む・古いものを消す
  core/logging_setup.py 文字のログ(launcher はこの端末、server / app は出力先)
  web.py           要求・応答・経路表(標準ライブラリだけ)
  routes/          URL ごとの受付
  services/        業務ロジック(一覧・Val・半角化・リネーム・印刷・パスの読み方)
  repositories/    最後に使えたパスの覚え書き
  models/          一覧のデータの形
  templates/ static/  画面(判断はすべてサーバ。JS は表に写すだけ)
config/app.json   アプリID・表示名・版・ポート(ここだけが出どころ)
```

DB は使いません。一覧は押すたびにフォルダから作るので、古いデータが残ることも、
複数の PC の書き込みがぶつかることもありません。リネームは実行の瞬間にフォルダを
読み直し、下見のときと違えば何も変えずに断ります(別の PC が同時に触ったとき)。

## 試験

```bash
python -m unittest discover -s tests -t . -v
```

Python 3.8 と 3.13 で通ることを確かめています。`tests/test_vba_export.py` は `vba/export/` の VBA を読んで、VBA が読んでいた班のフォルダ名・並べ替えの行数・文言・フォームの表記が Python 側と食い違っていないかを見ます。
